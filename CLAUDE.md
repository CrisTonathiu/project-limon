# CLAUDE.md

## Git

- Never commit on `main`, and never push to it.
- Before committing, create a branch from `main`:
  - `feat/<branch-name>` for a feature
  - `chore/<branch-name>` for any chore work, such as a fix

## UI

- UI work in `apps/patient` follows `docs/ui/UI-BRIEF.md` (tokens, motion, screen specs); the visual references are in `docs/ui/mockups/`.
